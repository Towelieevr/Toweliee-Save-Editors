# Toweliee's Save Editors - update channel

This repo holds the update list (`manifest.txt` in the [updates release](https://github.com/Towelieevr/Toweliee-Save-Editors/releases/tag/updates)) that the **Toweliee's Save Editors** PS4 installer app reads when you choose **Check for updates online**.

The editors themselves live in their own repos:

- [Borderlands 2](https://github.com/Towelieevr/Borderlands-2-Save-Editor-PS4)
- [Borderlands 3](https://github.com/Towelieevr/Borderlands-3-Save-Editor-beta)
- [Borderlands: The Pre-Sequel](https://github.com/Towelieevr/Borderlands-Pre-Sequel-Save-Editor-beta)
- [Tiny Tina's Wonderlands](https://github.com/Towelieevr/Tiny-Tinas-Wonderlands-Save-Editor-beta)

Every file the app downloads is checked against the SHA-256 listed in the manifest before it's installed.
